# Manta Prototypes

Manta 제품 프로토타입(디자인팀 AI 워크샵과는 별개 프로젝트)을 아카이브하고 재사용하기 위한 저장소입니다.

## 구조

프로젝트마다 하나의 폴더로 관리합니다. 저장소 전체가 Vercel 프로젝트 하나(`manta-prototypes`)에 연결되어 있고, 각 폴더는 `https://manta-prototypes.vercel.app/<폴더명>/` 경로로 바로 접근할 수 있습니다.

## 프로토타입 목록

| 폴더 | 배포 링크 | 설명 | 관련 문서 |
|---|---|---|---|
| [`context-badge`](./context-badge) | [바로가기](https://manta-prototypes.vercel.app/context-badge/) | 홈 그리드 카드에 붙는 맥락 뱃지(Like 'OO', Trending in OO 등) 실험 | [One Pager](https://app.notion.com/p/ridi/One-pager-3a52d79d77078063a164d6bd1179c950), [Figma](https://www.figma.com/design/RGRDcAJgYscJRhIxKIqni6/1.-2026-2Q?node-id=14682-55473) |
